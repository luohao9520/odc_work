Rule Book

计算规则

  • 分母：应出勤工作日 = 普通工作日 - 调休节假日 + 周末补班日 - 请假日。
  • 公司打卡分：居家办公、未选择的均按工作日属于分母；请假按休息日处理，不计入分母。
  • 分子：公司打卡天数 = 请假和居家办公不计入分子。
  • 每月达标线 = 需公司打卡天数 = 需应出勤打卡工作日 * 达标线。
  • 截至目前达标线 = 需截至目前公司打卡天数 = 需月初至当日应出勤工作日 * 达标线。
  • 月度公司打卡天数 = 当前日（应出勤工作日 - 请假出勤天数）

Quick Guide

系统使用指南

  1. 目标达标线：直接在页面顶部修改目标保留，保存后自动同步所有月份计算。
  2. 手动排班：在月度日历中点击日期会切换“是否办公”并锁定该天，办公日默认不排班，遇休息日自动调整。
  3. 智能排班：勾选“覆盖整月日期”自动将本月全设为办公日，再检查空闲月历并手动调整。
  4. 智能推荐排班：默认只调整今天及之后，今天在日历中手动确认，勾选“覆盖整月日期”会自动整月保持规则。
  5. 节假日切换：节假日同步和公休日调整，请在“节假日调整”页面处理。
