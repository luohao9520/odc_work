Rule Book

计算规则

  1. 分母 = 应统计工作日 = 普通工作日 - 调休放假日 + 周末补班日 - 请假日。
  2. 公司打卡、居家办公、未选择的可统计工作日属于分母；请假按休息日处理，不计入分母。
  3. 分子 = 公司打卡天数；请假和居家办公不计入分子。
  4. 整月出勤率 = 整月公司打卡天数 ÷ 整月应统计工作日。
  5. 截至今日出勤率 = 截至今日公司打卡天数 ÷ 截至今日应统计工作日。
  6. 最低公司打卡天数 = 当cell(应统计工作日 × 目标出勤率)

Quick Guide

系统使用指南

  1. 目标达标线：直接在页面顶部徽章内修改目标出勤率，保存后会影响所有月份计算。
  2. 手动选择：你在月度日历里手动点选的日期不会被”智能排班“或”工作日全设为公司“覅该
  3. 清空本月选择：会按”包含过去日期“开关决定清空范围，并清空范围内的手动选择
  4. 智能推荐排班：默认只调整明天及之后；今天在日历中手动确认，勾选“包含获取日期”才会重排整月
  5. 节假日：节假日同步和公司日历差异，请在“节假日调整”页面处理。
